Real Work, Real Physics

Open-loop misses by 202 mm. LitSim lands within 3.0 mm.

LitSim is my own robot-simulation engine — built from scratch on MuJoCo — and this is a real task run through it. A faithful UR5e arm is designed on a nominal model, then run on unseen real-world hardware: heavier links, motor lag, and noisy, delayed encoders. Left, the usual approach (burn the setpoints) ends 199 mm away. Right, LitSim's closed-loop controller watches the encoders and lands on target — and not only in the world shown here: across all 16 randomised hardware worlds it never missed by more than 3.0 mm.

The same controller, with no retuning whatsoever, dropped onto a different industrial arm: the Franka Emika Panda. It has seven joints (not six), no tool-mounting site — so LitSim resolves the hand through a body Jacobian instead — and stiffer servos. Left, the open-loop setpoints miss by 218 mm. Right, the identical LitSim law lands on target. Across 16 unseen randomised hardware worlds it never missed by more than 6.8 mm (median 1.8 mm).
